En resumen

La caixa-do-agente (caja del agente) es un kit gratuito para quien ya usa agentes de IA en la computadora, como Claude Code, Codex o DeepSeek Harness. El harness es el software alrededor del modelo: ejecuta los comandos, controla los permisos y guarda el historial. El kit le pone nota de 0 a 10 al harness que usas y ejecuta cualquier agente o comando en una caja Docker desechable, sin internet y sin tus archivos de contraseñas (.env). Necesitas Docker y Python 3.

Qué es

Tres piezas, una idea: cuida el cuerpo del agente

DeepSeek mostró que el mismo modelo cambia casi 9 puntos solo con cambiar el harness. Este kit lleva esa idea a tu máquina.

📊 auditar.py

Lee la configuración de Claude Code, Codex y DeepSeek Harness y da una nota de 0 a 10 en 6 capas: caja, aprobación, bloqueos, verificación, contexto y secretos. Solo lee, no cambia nada.

📦 caixa.sh

Copia el proyecto sin los secretos, ejecuta el comando en un contenedor sin red y con tope de memoria, CPU y tiempo, muestra qué cambió y borra todo. El original solo cambia con --aplicar.

🗺️ Mapa de kits

Cada capa que falte apunta a un kit INEMA que la resuelve: bloqueos contra inyección de prompt, lección que se vuelve bloqueo, memoria del proyecto, DeepSeek Harness local.

Cómo funciona

El ciclo de la caja: crea, ejecuta, destruye

Es el mismo ciclo que DeepSeek usa para entrenar a sus agentes (más de 380 mil cajas al mismo tiempo, según su artículo), a escala de una persona.

Copia sin .env ni claves→ Contenedor sin red→ Tope de memoria, CPU y tiempo→ Patch con los cambios→ Contenedor y copia borrados
Requisitos previos

Lo que necesitas

Linux con Docker. En macOS, instala antes brew install coreutils (trae gtimeout). El auditor funciona incluso sin Docker.

Docker

Para la caja. Verifica que responda:

# comando
docker --version

Python 3

Para el auditor (sin bibliotecas extra).

# comando
python3 --version

rsync

Para copiar el proyecto sin los secretos.

# comando
rsync --version | head -1
Guía de uso · paso a paso

De cero a la primera caja en 5 minutos

Los comandos usan solo lo que está en el repositorio. Los pasos 1 a 4, 6 y 7 se ejecutaron en esta máquina el 10/11/2026.

1

Descarga el kit

Clona el repositorio y entra en la carpeta.

git clone https://github.com/inematds/caixa-do-agente && cd caixa-do-agente
2

Comprueba que la caja funciona

14 verificaciones: .env y claves quedan fuera, red cerrada, original intacto, contenedor borrado, --aplicar funciona, --env pasa solo la variable pedida, y el auditor detecta secretos, sandbox desactivado y máquina sin harness.

bash testes/teste.sh  # termina con: TUDO OK (14/14)
3

Ponle nota a tu harness

Apunta a un proyecto tuyo. El auditor lee la configuración de Claude Code, Codex y DeepSeek Harness (el agente de código abierto de DeepSeek, comando dsh): ~/.claude/settings.json, ~/.codex/config.toml y ~/.dsh/settings.yaml (si existen), y el propio proyecto. Cada capa vale 2 puntos (OK), 1 (MEIO) o 0 (FALTA); la nota es la suma dividida entre 12, por 10.

python3 auditar.py ~/meu-projeto        # nota de 0 a 10 + el siguiente paso de cada capa
python3 auditar.py ~/meu-projeto --json # lo mismo, para usar en un script
4

Ejecuta algo en la caja

Todo lo que va después de -- se ejecuta dentro del contenedor, en la copia del proyecto. Sin red por defecto.

./caixa.sh ~/meu-projeto -- npm test
./caixa.sh ~/meu-projeto --imagem python:3.12-slim -- python3 -m unittest
5

Ejecuta un agente en la caja

Los agentes necesitan hablar con el modelo, así que habilita la red con --rede. La clave del modelo solo entra si la pides, con --env NOME: la caja recibe únicamente esa variable de tu terminal, ninguna otra. Los archivos de contraseñas del proyecto siguen fuera. Para dar acceso a una carpeta tuya, usa --montar origem:destino:ro (:ro = solo lectura).

./caixa.sh ~/meu-projeto --rede -- npx -y @deepseek-ai/dsh@latest --help  # probado: 1.ª vez ~5 min (descarga el paquete)
export ANTHROPIC_API_KEY=...
./caixa.sh ~/meu-projeto --rede --env ANTHROPIC_API_KEY -- npx -y @anthropic-ai/claude-code -p "rode os testes e corrija o que falhar"
6

Revisa y aplica

Cada ejecución que cambia archivos guarda un caixa-AAAAMMDD-HHMMSS.patch: un archivo de texto con la diferencia (el diff) de todo lo que cambió. Queda en la carpeta desde donde ejecutaste el comando (o en la que indiques con --patch PASTA). Léelo antes. Para copiar los cambios de vuelta, usa --aplicar (pide confirmación; un archivo borrado en la caja no se borra en el original).

less caixa-*.patch
./caixa.sh ~/meu-projeto --aplicar -- npm run format
7

Ajusta los topes

Por defecto: imagen node:22-slim, 4 GB de memoria, 2 CPU, 30 minutos.

./caixa.sh ~/meu-projeto --memoria 8g --cpus 4 --tempo 7200 -- make build

Límites

Lo que la caja no hace

No es una máquina virtual

Docker aísla archivos, red y recursos, pero comparte el núcleo del sistema. Para código en el que no confías en absoluto, usa una VM.

Con red, hay salida

Con --rede, el agente puede enviar hacia afuera lo que esté en la copia. Los secretos ya quedaron fuera, el resto no.

El auditor señala, no garantiza

Lee las configuraciones más comunes. Una nota alta no reemplaza revisar lo que el agente puede hacer.
